# Futuro: captação de leads por formulário

Esta funcionalidade não está ativa no site.

Quando o projeto avançar, avaliar uma integração de servidor para registrar o
formulário “Agende sua Visita” em uma base privada. Os dados mínimos previstos
são: data, nome do responsável, idade da criança, modalidade, origem do botão,
status do envio, abertura do WhatsApp e UTM de campanha.

Requisitos para a implementação futura:

- dados pessoais nunca devem ser enviados ao Google Analytics;
- credenciais, IDs privados e tokens devem permanecer no servidor/configuração
  protegida, nunca no navegador ou repositório;
- aplicar proteção contra spam, validação dos campos, controle de acesso e
  política de privacidade compatível com a LGPD;
- registrar a origem de cada CTA, como banner da página inicial, cabeçalho e
  página de admissão.
