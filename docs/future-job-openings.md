# Futuro: seção de Vagas

A página pública de Vagas apresenta o processo de seleção e direciona a intenção
de vaga para o WhatsApp. Ela não recebe currículos pelo site neste momento.

Em uma futura evolução, caso o formulário envie candidaturas por e-mail, os
destinatários e as credenciais do provedor devem ficar exclusivamente em variáveis
de ambiente do servidor — nunca no HTML ou JavaScript entregue ao navegador.
